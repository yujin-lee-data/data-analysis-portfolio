# 05. 대학별 정시 산출식 규칙 테이블화와 검증기

> **무엇을 다루나** — 문서에 문장과 표로 흩어져 있는 규칙을 계산되는 데이터로 옮길 때
> **무엇을 검증해야 하는가**를 정리한 개인 연습입니다. 소재로는 공개된 대학입학전형 시행계획을 썼습니다.
>
> 대학이나 입시 서비스가 실제로 쓰는 합격예측 산출식이 아니며 내부 자료를 쓰지 않았습니다.
> 전부 **공개된 시행계획**에 적힌 표만 옮겼습니다.

---

## 1. 왜 만들었나

대학별 전형 규칙은 문서(모집요강·시행계획) 안에 문장과 표로 흩어져 있습니다.
이걸 계산되는 형태로 옮기는 순간 두 가지가 생깁니다.

- 대학이 늘어날수록 사람이 표를 다시 읽어야 한다
- 잘못 옮겨도 값은 그냥 나온다 — 틀렸다는 신호가 없다

그래서 **옮기는 코드보다 옮긴 것을 검사하는 코드를 먼저** 만들었습니다.

## 2. 사용한 공개 자료

| 항목 | 출처 |
|---|---|
| 수능 영역별 반영 배점, 영어·한국사 등급표 | 연세대학교 서울캠퍼스 「2027학년도 대학입학전형 시행계획」(공개본) 정시모집 일반전형 「대학수학능력시험 반영점수 산출방법」 |
| 원문 | https://www2.yonsei.ac.kr/entrance/plan/2027_plan.pdf |

## 3. 규칙 테이블 설계

한 대학·한 전형·한 계열이 하나의 규칙 묶음입니다.
**대학이 늘어나도 코드를 고치지 않고 행만 늘리면 되도록** 만들었습니다.

`rules/rule_area.csv` — 영역별 배점

| 학년도 | 대학 | 전형 | 계열 | 영역 | 배점 | 활용지표 |
|---|---|---|---|---|---|---|
| 2027 | 연세대학교(서울) | 일반전형 | 인문 | 국어 | 300 | 표준점수 |
| 2027 | 연세대학교(서울) | 일반전형 | 인문 | 수학 | 200 | 표준점수 |
| 2027 | 연세대학교(서울) | 일반전형 | 인문 | 탐구 | 200 | 표준점수 |
| 2027 | 연세대학교(서울) | 일반전형 | 인문 | 영어 | 100 | 등급 |

요강에 적힌 **합계**, **탐구 반영 과목 수**, **영어 9개 등급 환산점수**, **한국사 9개 등급 감점**은
각각 별도 표로 두었습니다. 한 표에 다 넣으면 나중에 어느 값이 요강 원문이고
어느 값이 계산 결과인지 구분되지 않습니다.

## 4. 검증 항목 여섯 가지

| | 무엇을 보는가 |
|---|---|
| V1 | 영역 배점의 합이 요강에 적힌 합계와 같은가 |
| V2 | 한 계열 안에서 활용지표가 두 종류 이상 섞여 있지 않은가 |
| V3 | 등급 환산표에 1~9등급이 다 있고 값이 등급 순서와 어긋나지 않는가 |
| V4 | 탐구 반영 과목 수가 규칙에 적혀 있는가 |
| V5 | 배점이 비었거나 0 이하인 행이 없는가 |
| V6 | 규칙의 적용 학년도가 하나로 통일되어 있는가 |

## 5. 의도적으로 넣은 오류 3건과 검출 결과

검증기가 실제로 잡는지 확인하려고 규칙을 일부러 틀리게 바꿔 돌렸습니다.

| 넣은 오류 | 검출 |
|---|---|
| 인문 국어 배점 300 → 250 | `V1 배점 합 불일치 : 연세대학교(서울) 인문 — 배점 합 750 vs 요강 합계 800` |
| 탐구 영역의 활용지표를 원문과 다른 값으로 변경 | `V2 활용지표 혼용 : ('연세대학교(서울)','일반전형','인문') — ['백분위','표준점수']` |
| 영어 5등급 행 삭제 | `V3 영어 등급 누락 : [5]` |

의도적으로 넣은 오류 3개가 모두 검증 조건에 걸렸습니다. 전체 출력은 `output/validation_result.txt`에 있습니다.

## 6. 결측 처리 원칙

성적이 비어 있을 때 **0점으로 계산하지 않고 산출 자체를 멈춥니다.**

```
탐구 없음  → (None, '산출 불가 — 탐구 성적이 없음')
한국사 없음 → (None, '산출 불가 — 한국사 성적이 없음')
```

0으로 채우면 값은 나오지만 그 값은 틀린 값입니다. 틀린 값이 나오는 것보다
안 나오는 편이 낫다고 봤습니다.

## 7. 이 연습에서 실제로 걸린 것

같은 성적을 인문 규칙과 자연 규칙에 각각 넣었더니 **556.5점**과 **623.5점**이 나왔습니다.
처음에는 자연 쪽이 유리한 줄 알았는데 두 계열의 **총점 자체가 800점과 900점으로 달랐습니다.**
이 환산점수만 놓고 어느 쪽이 유리한지는 판단할 수 없었습니다.

## 8. 한계

- 참고한 시행계획 공개본만으로는 **최종 환산에 필요한 세부 값까지 확인할 수 없었습니다.**
  공개된 반영 배점 범위에서 **단순 환산**까지만 계산했고 이 값은 실제 대학 환산점수가 아닙니다.
- 대학 1곳, 전형 1개, 계열 2개까지만 다뤘습니다.
- 수시 전형과 수능최저학력기준은 다루지 않았습니다.
